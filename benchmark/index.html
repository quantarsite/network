Methodology
Parameter Detail
Benchmark type Signature verification cost per transaction, measured locally without network overhead. The 2-core figure runs one verifier per thread.
AND-composition Each transaction requires a valid ML-DSA-87 signature AND a valid SLH-DSA signature. Both are verified sequentially per transaction.
Sample size 5,000 ML-DSA verifications and 2,000 SLH-DSA and HYDRA-X verifications, after warm-up. Mean with normal-approximation 95% CI; no outliers removed.
Parallelism Single thread for the per-core figures. The current testnet node verifies transactions one by one; parallel verification is planned.
Keys Pre-generated keypairs, excluded from timing. Benchmark measures pure verification cost.
Implementation Rust. pqcrypto-mldsa for ML-DSA-87 · fips205 for SLH-DSA-SHA2-256s, the same crates the testnet node uses.
